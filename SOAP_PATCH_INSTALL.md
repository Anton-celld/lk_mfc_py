# Применение подготовительного SOAP-патча для lk_mfc_py

Патч содержит только код/примеры конфигурации. Базу, `data/`, `.env`,
`config.json`, `portal_config.json` и пользовательские вложения в архив НЕ кладём.

1. Сделайте резервную копию рабочего каталога и базы до любого обновления.
2. Остановите существующий сервис (`docker compose stop mfc` или `systemctl stop lk-mfc-beta`).
3. Распакуйте `lk_mfc_soap_patch.zip` **из корня проекта `lk_mfc_py`**:

   ```bash
   unzip -o /путь/к/lk_mfc_soap_patch.zip
   ```

4. Если включаете SOAP, установите зависимости:

   ```bash
   python -m pip install -r requirements-soap.txt
   ```

5. Настройте `MFC_ONEC_TRANSPORT=soap`, `MFC_ONEC_WSDL`, логин,
   пароль и `onec.soap.operations` по реальному WSDL; см. `SOAP_INTEGRATION.md`.
6. Запустите сервис, проверьте вход и чтение данных на тестовой учётке.
   **Не отправляйте реальные заявки до подтверждения SOAP-контракта и защиты от дублей.**

Режим по умолчанию — `http`. Если настройки SOAP не внесены, старый HTTP
адаптер работает как прежде. HTTP API самого МФЦ и других микросервисов не
меняется. Переход на `X-Service-Token` в этот патч не входит.

Проверки, выполненные при подготовке: тесты `tests/test_onec_soap.py`
и `tests/test_portal_sso.py`, компиляция Python, синтаксис установочного
скрипта и JSON-конфигураций. Тесты с защищённым WSDL/1С не выполнялись.
